# blaise-connect
Plateforme web de gestion scolaire réalisée dans le cadre d’un stage avec React, FastAPI et PostgreSQL : gestion des élèves, familles, enseignants, classes et notes.

## Version

La version de référence de BlaiseConnect est inscrite dans le fichier `VERSION` à la racine du projet.
Les métadonnées du frontend et du backend doivent toujours reprendre cette même version.
Une version évolue lorsqu'un ensemble de changements est validé pour une release, pas à chaque commit.
